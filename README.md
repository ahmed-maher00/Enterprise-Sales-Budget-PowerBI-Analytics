# 📊 Enterprise Sales & Budget Analytics System (Power BI)

## 📌 Executive Summary
An end-to-end Power BI analytics solution designed to evaluate sales performance against corporate budgets ($16.47M sales, 97.7% achievement). This project identifies key variance drivers, predicts future revenue trends, and automates alert notifications for budget deviations.

---

## 🛠️ Key Technical Features & Architecture
- **Data Modeling:** Scalable **Star Schema** with robust relational architecture.
- **Performance Optimization:** Implemented **Incremental Refresh** (archiving 20 years of historical data & refreshing current periods).
- **Advanced Analytics & Calculations:** Complex DAX measures evaluating Year-over-Year (YoY), Like-for-Like (LfL) growth, and variance analysis.
- **Diagnostic Analytics:** Identified a **-$395.96K budget gap** primarily driven by new product launches (*Touring Bikes* subcategory).
- **Forecasting & Predictive Analysis:** 6-month statistical forecasting and 3-month rolling momentum.
- **Automation & Cloud:** Deployed to **Power BI Service** with scheduled refresh and **Power Automate** flow for automated real-time alerts.

---

## 💻 Tech Stack
- **Business Intelligence:** Power BI Desktop, Power BI Service
- **Query & Modeling Language:** DAX, Power Query (M), DAX Studio
- **Automation:** Power Automate
